# ⚠️ 仪表真正认的 arrowId（2026-10-02 修正）

**别用上面的 `E_ICON_NAVI_*`（112~138）当转向码。** 那是车机自己的「联动图片」id，
发给仪表会被当成别的图标——实测把「左转」显示成了「大转盘转弯」。

仪表 `INaviInteraction.updateTurnByTurnArrow(int)` 认的是**原厂百度地图用的那套值**。
权威来源：`Dueros-BaiduMapAuto.apk` 里 `com.baidu.a.a`（NaviDashboardManager）的
`HashMap<百度图标名, arrowId>`：

| 百度图标名 | arrowId | 含义 |
| --- | --- | --- |
| turn_start | 101 | 出发 |
| turn_left（含 2/3 岔左变体） | **102** | 左转 |
| turn_right（含 2/3 岔右变体） | **103** | 右转 |
| turn_left_front / _side / branch_left / lf_* / rf_2branch_left 等 | 104 | 左前方 |
| turn_right_front / _side / branch_right / lf_2branch_right 等 | 105 | 右前方 |
| turn_left_back | 106 | 左后方 |
| turn_right_back | 107 | 右后方 |
| turn_back（含变体） | 108 | 掉头 |
| turn_front / branch_center / *_side_main / branch_*_straight | 109 | 直行 |
| turn_via_1..4 | 110 | 途经点 |
| turn_ring | 111 | 环岛 |
| turn_ring_out / turn_ring_front | 112 | 环岛出口/前方 |
| turn_tollgate | 114 | 收费站 |
| turn_dest | 115 | 到达 |
| turn_along | 120 | 沿路 |
| turn_ring_left / leftback / leftfront | 141 | 环岛左 |
| turn_ring_right / rightback / rightfront | 142 | 环岛右 |
| turn_ring_back | 143 | 环岛掉头 |

映射实现见 `app/src/main/java/com/awen/amapdim/AmapIcon.java`（高德 id → 上表 arrowId）。
高德 id=3=右转 是实车验证过的；其余按图标形状推，复现步骤见 `仪表盘-导航.md` 第 3 节，
不对就照这张表改数。
