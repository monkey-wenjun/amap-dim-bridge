# 高德转向图标 id 对照表

高德车机版广播里的 `ICON` / `NEW_ICON` 就是高德自带资源
`res/drawable-hdpi-v4/navistate_landback_<id 的十六进制>.png`（`res` 里另有
`navistate_landfront_*` 是路口放大图，`navistate_auto_landback_*` 是车机版另一套）。

把 APK 里这套 PNG 解出来按 id 看，就得到下表（`id=3` 已实车验证：导航到「红军营东路」时
高德卡片上画的就是右转，广播 `ICON=3`）：

| 高德 id | 图 | 含义 |
| --- | --- | --- |
| 0  | 向上箭头 | 直行 |
| 1  | 上折左 | 左转 |
| 2  | 上+左 | 直行+左（左前方） |
| 3  | 上折右 | **右转（实测验证）** |
| 4  | 上+右 | 直行+右（右前方） |
| 5  | 掉头 | 掉头 |
| 6  | 左+右 | 前方左右 |
| 7  | 十字 | 十字路口 |
| 8  | 右掉头 | 右掉头 |
| 9  | 直行+右掉头 | 复合 |
| 10 | 直行+左掉头 | 复合 |
| 11 | 复合 | 复合路口（左） |
| 12 | 复合 | 复合路口（右） |
| 13 | 直行+汇入 | 直行 |
| 14 | 复合 | 复合路口（掉头） |
| 15 | 公交 | 公交专用道 |
| 16 | 复合 | 复合路口 |
| 17 | 复合 | 复合路口 |
| 18 | 复合 | 复合路口 |

| 20 | 复合 | 复合路口 |
| 21 | 公交 | 公交专用道 |

## 仪表端（ecarx）图标码

取自 `/system/app/XCDimInteractionService.apk` 的
`com.ecarx.dim_interaction.template.dimscreen.LinkedImageMapping` 字段值（byte）：

| 常量 | 值 | 常量 | 值 |
| --- | --- | --- | --- |
| E_ICON_NAVI | 112 | E_ICON_NAVI_TURN_R_D | 119 |
| E_ICON_NAVI_STRAIGHT | 113 | E_ICON_NAVI_TURN_L_D | 120 |
| E_ICON_NAVI_TURN_BACK | 114 | E_ICON_NAVI_KEEP_R | 121 |
| E_ICON_NAVI_TURN_R_T | 115 | E_ICON_NAVI_KEEP_L | 122 |
| E_ICON_NAVI_TURN_L_T | 116 | E_ICON_NAVI_EXIT_R | 123 |
| E_ICON_NAVI_TURN_R | 117 | E_ICON_NAVI_EXIT_L | 124 |
| E_ICON_NAVI_TURN_L | 118 | E_ICON_NAVI_ROUND | 125 |
| E_ICON_NAVI_TOLL | 126 | E_ICON_NAVI_DEST | 127 |
| E_ICON_NAVI_FERRY | 128 | E_ICON_NAVI_JCT | 135 |
| E_ICON_NAVI_DEST_1..5 | 129-132,136 | E_ICON_NAVI_ENTRY_R/L | 133/134 |
| E_ICON_NAVI_SA | 137 | E_ICON_NAVI_TUNNEL | 138 |

映射实现见 `app/src/main/java/com/awen/amapdim/AmapIcon.java`。
**除 id=3 外的对应关系是按图标形状推的，需要在真车仪表上看一眼再微调**；
没把握的复合路口统一回落到通用导航图标，宁可少画不画错。
