# 左侧栏（hotseat）那条「百度地图」是怎么没的 / 怎么把高德加进去

## 结论（2026-10-02）

**是我的操作弄掉的**，具体是 `pm block com.baidu.naviauto` 那一步（当时为了验证
「能不能卸掉百度地图」）。`pm unblock` 之后应用本身恢复正常，但**左侧栏那条记录回不来**。

## 机制：左侧栏不是动态的，是 launcher.db 里的固定记录

左侧竖排栏 = Launcher3 的 **hotseat**（`container = -101`）。它的默认布局来自
`XCLauncher3.apk` 里的 `res/xml/dw_ecarx_hotseat.xml`：

```xml
E: favorite  launcher:container="-101"  packageName="ecarx.settings"      screen=0
E: favorite  launcher:container="-101"  packageName="com.ecarx.btphone"   screen=1
E: favorite  launcher:container="-101"  packageName="com.ecarx.multimedia" screen=2
E: favorite  launcher:container="-101"  packageName="com.baidu.naviauto"  screen=3   ← 百度地图
```

这份 XML **只在 LauncherProvider 第一次建库时灌进 `launcher.db` 的 favorites 表**，
之后 Launcher3 只读数据库。当某个包「不可用」（被 `pm block` 屏蔽也算）时，
Launcher3 的加载流程会**把对应的 favorite 记录删掉**；`pm unblock` 之后
Launcher3 不会重新灌默认布局，所以那条就永久消失了（除非有 root 改 db 或重灌布局）。

DuerOS 的「默认导航应用」偏好（`prefs_amap`）跟 launcher 无关，不是这次的原因。

## 能不能程序化加回去？——不加 root 不行

`LauncherProvider`（authority `ecarx.launcher3.settings`）是 exported 的，但权限卡得很死：

| 权限 | protectionLevel | 第三方 App 能不能拿到 |
| --- | --- | --- |
| `ecarx.launcher3.permission.READ_SETTINGS` | `0x0` normal | ✅ 能读 hotseat 现状 |
| `ecarx.launcher3.permission.WRITE_SETTINGS` | `0x3` signature\|privileged | ❌ 不能写 |
| `ecarx.launcher3.permission.RECEIVE_FIRST_LOAD_BROADCAST` | `0x3` signature\|privileged | ❌ 不能触发重灌默认布局 |

`ecarx.launcher3.InstallShortcutReceiver`（`com.android.launcher.action.INSTALL_SHORTCUT`）
在这个 build 里没有在 manifest 注册（只在 Launcher 运行时动态注册过），而且 AOSP 的实现
只往 **workspace** 加，不加 hotseat，所以也指望不上。

## 可行的做法

1. **手工拖（无 root，最快）**：打开应用列表页 → 长按「高德地图」→ 拖到左侧栏空出来的位置
   （在 screen=3 那个槽）。Launcher3 的 hotseat 一般允许从应用列表拖入。
2. **不 root 的自动化**：车机 adb 连上后，用 `sendevent` 合成「按下 → 等 600ms → 移动 → 抬起」
   把高德图标拖到左侧栏（`input swipe` 不行，必须中间停顿才会触发长按拖拽）。
3. 如果这个 launcher 的 hotseat 不接受拖放，就只能 root 改
   `/data/data/ecarx.launcher3/databases/launcher.db` 的 `favorites` 表
   （插一行 `container=-101, screen=3, itemType=0, intent=<高德的启动 Intent 的 #Intent;...;end 串>`），
   或者清 launcher 数据让它重灌默认布局（会把整个桌面布局重置）。

## 教训

`pm block` 在这台车上是**会留后遗症**的：不光是应用起不来，Launcher3 会顺手把它从
hotseat/db 里删掉，而 `pm unblock` 不会恢复。以后要验证「屏蔽」之前先记下这一条。
